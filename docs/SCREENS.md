# Экраны · Dante Florens · Дарующий расцвет / Расцвет

Интерактивный кликабельный прототип (демо для ЛПР): [`/prototype-rascvet.html`](../public/prototype-rascvet.html) — пульт, магнит, пакт, карта клиента, сканер кассира.

## Онбординг за 2 шага (пилот)

Сжимает паспорт + локомотив + тумблер коопетиции в один экран, затем ИИ-подбор связок.

### Шаг 1 из 2 · Магнит (`#onboard` / `#cabinet?pane=onboard`)

```
+-------------------------------------------------------+
|  [Лого: РАСЦВЕТ]                        Шаг 1 из 2    |
|                                                       |
|  Настроим ваш поток клиентов без бюджета на рекламу   |
|                                                       |
|  1. Ваша ниша и район города                         |
|  [ Стоматология • Центр / ул. Ленина             v ]  |
|                                                       |
|  2. Ваш «Подарок-локомотив» для клиентов партнёров    |
|  (То, что ценно для клиента, но дёшево для вас)       |
|  [ Бесплатная профгигиена + 3D-снимок (ценность 4500₽)]|
|  [Кнопка ИИ]: Придумать 3 сильных подарка за меня     |
|                                                       |
|  3. Готовы принимать «горящие» отказы от коллег?      |
|  [ Тумблер ВКЛ ] Режим Коопетиции (+50% Лид-коинов)   |
|                                                       |
|  [ ===== ЗАПУСТИТЬ «ИИ-РАСЦВЕТ» И НАЙТИ СВЯЗКИ ==== ] |
+-------------------------------------------------------+
```

**Поля → данные:** ниша+район → паспорт; текст подарка (+ ценность) → gift; тумблер → `mode=coopetition` (×1.5 коинов на hot/overflow без денежного RevShare — см. ТЗ).  
**CTA** → матчмейкер; без заполненных 1–2 — мягкий блок.  
**Копирайт:** «без бюджета на рекламу» ок; не писать «0 ₽ навсегда». «+50% Лид-коинов» = ×1.5 в ledger, не выплата на р/с.

### Шаг 2 из 2 · Связки

После CTA «ИИ-Расцвет» — те же карточки, что в блоке рекомендаций штаба (смежная / коопетиция). Выбрать → запустить связку / активировать пакт → QR.

## Штаб кабинета (`#cabinet`)

Главный экран после онбординга. Только подтверждённые метрики (погашения), без прогноза «сколько клиентов будет».

```
+-------------------------------------------------------+
|  Клиника «ДентаПлюс» • Пилот: Казань      [Тариф PRO] |
+---------------------------+---------------------------+
|  ВЫРУЧКА С ПАРТНЁРОВ      |  КОШЕЛЁК ЛИД-КОИНОВ       |
|  348 500 ₽                |  1 850 LC                 |
|  +42 визита до кассы      |  Начислено после гашения  |
|  Рекламный бюджет: 0 ₽    |  [ Усилить охват → ]      |
+---------------------------+---------------------------+
|  ЭКСТРЕННЫЙ ПЕРЕЛИВ (Режим Коопетиции)                |
|  Нет окна сегодня или нет нужного аппарата?           |
|  [ ПЕРЕДАТЬ ГОРЯЩЕГО КЛИЕНТА (2 клика) ]              |
+-------------------------------------------------------+
|  ИИ-РАСЦВЕТ РЕКОМЕНДУЕТ СВЯЗКИ (совместимость >90%)   |
|                                                       |
|  [Карточка 1 • Смежная ниша • 96%]                    |
|  Студия красоты «Мята» (300 м от вас)                 |
|  Идея: вы дарите их клиенткам сертификат на гигиену,  |
|  они дарят вашим — укладку перед важным событием.     |
|  [ Запустить связку в 1 клик ]  [ Посмотреть скрипт ] |
|                                                       |
|  [Карточка 2 • Коопетиция • 92%]                      |
|  Центр томографии «Вокс» (свободны окна утром)        |
|  Идея: перелив на КТ с «якорем возврата» на           |
|  бесплатную расшифровку к вашему врачу.               |
|  [ Активировать пакт ]                                |
+-------------------------------------------------------+
|  ЖИВАЯ ЛЕНТА СЕТИ (Пульс города)                      |
|  • 15:40 — Погашен ваш QR от Кофейни «Зерно» (+8 200₽)|
|  • 14:12 — Ваш клиент активировал подарок в «Мяте»    |
|            (+150 Лид-коинов в кошелёк)                |
+-------------------------------------------------------+
```

**Блоки → данные:** выручка/визиты только из `redeemed` + сумма чека; LC — баланс ledger; «Усилить охват» → трата LC на размещение оффера; перелив → `#cabinet?pane=hot` / handoff 2 клика; карточки → match + create bundle / coopetition pact; лента → события сети (issued / activated / redeemed), без чужих ПДн.

**Копирайт-стоп:** не «зачислено на счёт» (звучит как р/с) → «в кошелёк» / «на баланс LC». «Рекламный бюджет: 0 ₽» = факт по каналу партнёров, не обещание навсегда. Совместимость % — score матчмейкера, не гарантия чека.

## Новая связка: коопетиция (`#cabinet?pane=bundles` / create coopetition)

Экран после «Активировать пакт» / выбора карточки коопетиции. Три блока до выдачи QR: сертификат клиенту → якорь возврата → ledger-условия.

```
+-------------------------------------------------------+
|  < Назад          НОВАЯ СВЯЗКА: КООПЕТИЦИЯ            |
|                                                       |
|  Партнёр: Центр томографии «Вокс» (район Центр)       |
|                                                       |
|  1. Что получает клиент (Заботливый сертификат):      |
|  «Направление от ДентаПлюс: 3D-снимок челюсти со      |
|  скидкой 30% без очереди в течение 48 часов»          |
|                                                       |
|  2. Якорь возврата (Авто-бонус обратно к вам):        |
|  «После снимка ждём вас в ДентаПлюс — расшифровка КТ  |
|  и план лечения от главврача БЕСПЛАТНО»               |
|                                                       |
|  3. Условия в Ledger (Журнале сделки):                |
|  [✓] Джентльменский пакт: партнёр не предлагает       |
|      клиенту услуги лечения зубов (только КТ).        |
|  [✓] Награда вам: +225 Лид-коинов (коэф. ×1.5) строго |
|      после сканирования QR на кассе партнёра.         |
|                                                       |
|  [ ===== ПОДТВЕРДИТЬ И ПОЛУЧИТЬ QR + СКРИПТ ===== ]   |
+-------------------------------------------------------+
```

**Поля → данные:** сертификат → оффер купона; якорь → `reverseBonus` на лендинге claim; пакт → `pactBans` + `pactAcceptedAt`; награда → правило LC ×1.5 на событие `redeemed` (не на клик/активацию).  
**CTA** → publish bundle + QR + скрипт кассира/админа; без акцепта пакта — не публиковать.  
**Копирайт:** «Авто-бонус» = текст на лендинге купона, не автосписание денег. Награда только LC после гашения — без % на р/с.

## Предприниматель (кабинет после онбординга)

| Шаг | Экран | Что делает |
|-----|--------|------------|

## Покупатель (B2C)

### Лендинг подарка (`#claim?code=…`)

После активации (телефон/Telegram) клиент видит персональный купон. Базы не передаём между бизнесами: контакт уходит только владельцу подарка (бизнес B).

```
+-------------------------------------------------------+
|  [Лого Партнёра А]   ×   [Лого Вашего Бизнеса Б]      |
|                                                       |
|  +-------------------------------------------------+  |
|  |  ПЕРСОНАЛЬНЫЙ ПОДАРОК ДЛЯ ВАС                   |  |
|  |                                                 |  |
|  |  Профгигиена полости рта (ценность 4 500 ₽)     |  |
|  |  в клинике «ДентаПлюс»                          |  |
|  |                                                 |  |
|  |  [             КРУПНЫЙ QR-КОД             ]     |  |
|  |               Код: DF-849-210                   |  |
|  |                                                 |  |
|  |  Действует ещё: 13 дней 18 часов                |  |
|  +-------------------------------------------------+  |
|                                                       |
|  Адрес: ул. Ленина, 42 (3 минуты пешком)              |
|  Якорь возврата: после визита вас ждёт бонус          |
|     от [Партнёра А]  (только если связка coopetition) |
|                                                       |
|  [ ===== СОХРАНИТЬ В TELEGRAM В 1 КЛИК ===== ]        |
+-------------------------------------------------------+
```

**Поля → данные:** лого A/B из профилей связки; оффер + ценность; `code` + QR; таймер до `expiresAt`; адрес точки B; якорь — текст `reverseBonus` (показывать только в коопетиции); CTA — deep-link / share в Telegram с тем же кодом.  
**До CTA сохранения:** если купон ещё не активирован — экран с кнопкой «Забрать» + телефон/Telegram (см. шаг 2).  
**152-ФЗ:** на экране нет чужой базы; якорь — оффер обратно к A, не передача контакта A→B вне согласия активации.

| Шаг | Экран | Что видит |
|-----|--------|-----------|
| 1 | `#claim?code=…` | Лендинг подарка: QR, код, срок, адрес; при коопетиции — **якорь возврата** (вайрфрейм выше) |
| 2 | Форма контакта | Телефон/Telegram — только бизнесу подарка (B) |
| 3 | Персональный код | Тот же экран после активации — показать QR на кассе B |

## Кассир

### Сканер гашения (`#cashier/{token}`)

Короткая ссылка точки без полного ЛК. После «Подтвердить визит» — событие `redeemed`, сумма чека в аналитику, LC отправителю связки (×1.5 если hot/coopetition по правилам).

```
+-------------------------------------------------------+
|  Точка: ДентаПлюс (Ленина, 42)        [Смена открыта] |
|                                                       |
|  +-------------------------------------------------+  |
|  |                                                 |  |
|  |         [  НАВЕДИТЕ КАМЕРУ НА QR ]              |  |
|  |                                                 |  |
|  +-------------------------------------------------+  |
|                                                       |
|  Или введите 6-значный код вручную: [ DF - _ _ _ ]    |
|                                                       |
|  --- ПОСЛЕ СКАНИРОВАНИЯ ПОЯВЛЯЕТСЯ КАРТОЧКА ---       |
|  Подарок действителен!                                |
|  Клиент от партнёра: Студия «Мята»                    |
|  Подарок: Профгигиена 4 500 ₽                         |
|                                                       |
|  Введите итоговую сумму чека (₽):                     |
|  [  8 200                                          ]  |
|                                                       |
|  [ ===== ПОДТВЕРДИТЬ ВИЗИТ И ПОГАСИТЬ QR ===== ]     |
+-------------------------------------------------------+
```

**Поток:** камера/код → проверка статуса купона → карточка (партнёр, оффер) → сумма чека → redeem. Повторное гашение того же кода — блок.  
**Антифрод MVP:** лимит гашений с IP/устройства; аномальный spike → флаг Admin.  
**Копирайт:** на экране кассира не обещать «деньги партнёру на карту» — только факт визита; LC/RevShare в ledger уходят в кабинет Owner.

| Шаг | Экран | Что делает |
|-----|--------|------------|
| 1 | `#cashier/{token}` | Секретная ссылка точки, смена открыта (вайрфрейм выше) |
| 2 | QR / код → сумма чека | «Погасить» → `redeemed` + LC / ledger RevShare источнику |

## Принцип 152‑ФЗ

Базы не передаём. Клиент сам активирует купон. Протокол доверия запрещает коллеге пушить защищённые услуги отправителя этому контакту.
